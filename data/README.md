# Data setup

Download the original dataset from https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce and follow its current usage terms. Raw CSVs are not bundled or committed.

Required files:
- olist_customers_dataset.csv
- olist_geolocation_dataset.csv
- olist_orders_dataset.csv
- olist_order_payments_dataset.csv
- olist_order_reviews_dataset.csv

Upload them to your Databricks volume, then set DATA_DIR in the notebook. No API credentials or tokens are required in the notebook itself.
